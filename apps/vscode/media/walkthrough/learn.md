# Learn the basics

Team Topologies models an organisation as **teams** and the **interactions** between them.

**The four team types**

- **Stream-aligned** — delivers a continuous flow of value for a business domain.
- **Enabling** — helps other teams adopt new skills or technologies.
- **Complicated-subsystem** — owns a part that needs deep specialist knowledge.
- **Platform** — provides internal services that reduce cognitive load for stream-aligned teams.

**The three interaction modes**

- **Collaboration** — two teams work closely together for a while.
- **X-as-a-Service** — one team consumes something another team provides.
- **Facilitating** — one team helps another for a defined period.

**Working in the editor**

- Drag a team type from the palette onto the canvas, then double-click it to rename it in place.
  Or press Enter on a palette entry: it lands in the middle of the canvas, ready to be named.
- Drag an interaction mode from the palette and drop it over the teams it connects.
- Select an element to get its context pad, which renames it, adds an annotation, or deletes it.
- The inspector on the right edits the selected element: a team's type, name, description and
  colours, or an interaction's mode and label.
- Not sure which shape is which? The **Legend** names and explains every shape; switch it on or
  off in the menu (top-left). It starts hidden. **Keyboard shortcuts…** in the same menu lists
  every shortcut.
- Shift+drag on the canvas (or press `Ctrl/Cmd+A`) to select several elements and move them together.

Your changes are saved straight back into the `.tt` file, so diagrams version nicely in Git, and
`Ctrl/Cmd+Z` undoes them in the file's history.

New to the method? Start with [teamtopologies.com](https://teamtopologies.com/).
